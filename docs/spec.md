# LabirinthAi: лабиринты и ИИ

Игра из ИИ-Игротеки на Python. Общие правила — `PythonAiGames/docs/contract.md`, очередь — волна 4.

## 1. Режимы

1. **Пройди сам.**
   - Лабиринт с туманом: видно только рядом с собой.
   - Управление стрелками или WASD.
   - Таймер, рекорды, размер и тип лабиринта.
2. **Гонка с ИИ.** Ты и ИИ стартуете одновременно в одинаковых лабиринтах, у ИИ тот же туман. Кто первый выйдет.
3. **ИИ строит лабиринт для тебя.** Генератор подбирает лабиринт, в котором люди дольше всего блуждают. Учитывает твою статистику: где ты обычно ошибаешься.
4. **Смотреть ИИ.** Несколько агентов в незнакомом лабиринте: видно, как они исследуют. Для сравнения — классические алгоритмы.

## 2. Генераторы

- Классические: глубина (DFS), Прим, Краскал, Уилсон, «двоичное дерево», комнаты.
- Каждый генератор даёт «идеальный» лабиринт: ровно один путь между любыми клетками. Опционально — с петлями.
- Законы:
  - связность;
  - нет изолированных клеток;
  - для идеальных — число проходов на 1 меньше числа клеток.

## 3. ИИ

1. **Классика для сравнения**, видна в режиме «Смотреть»:
   - правило правой руки;
   - BFS и A*, которые видят весь лабиринт (подписано «читер, для сравнения»);
   - алгоритм Тремо.
2. **Обученный агент — главное.**
   - Видит только окрестность (как игрок в тумане) и свою память: карту того, что уже видел.
   - Сеть на numpy решает, куда идти.
   - Учится на тысячах **разных** лабиринтов, эволюцией или RL, чтобы проходить незнакомые.
   - Сравнение с правилом правой руки и с Тремо: число шагов до выхода.
3. **Генератор «посложнее для человека».**
   - Оценка трудности: длина решения, число развилок на пути, длина тупиков, «обманчивые» коридоры к выходу.
   - Подбор параметров эволюцией по этой оценке и по твоим реальным временам прохождения, которые записываются.
- **Честность:** в «Гонке» ИИ видит только туман вокруг себя. Закон-тест: изменение закрытой части лабиринта не меняет ход ИИ, пока он её не увидел.
- **Уровни:** новичок — правая рука; средний — ранний агент; сильный — обученный агент.
- **«Мысли ИИ»:** его карта памяти и куда он собирается пойти.

## 4. Проверки силы

- 1000 незнакомых лабиринтов каждого размера: среднее число шагов до выхода у агента, правой руки, Тремо, и отношение к кратчайшему пути.
- Генератор «посложнее»: среднее время прохождения ботом-«человеком» против обычного DFS.

## 5. План

1. Каркас по контракту.
2. Генераторы и законы.
3. Классические решатели, туман, закон честности.
4. Обученный агент, паспорт.
5. Генератор трудности, статистика игрока.
6. Окно: 4 режима, анимации, звук.
7. Тесты окна offscreen.
